# 人际关系诊断 — 三大人生课题定位法

> 「一个个体在想要作为社会性的存在生存下去的时候，就会遇到不得不面对的人际关系，这就是人生课题。」
>
> —— 第三夜·第20节「人生的三大课题」

基于《被讨厌的勇气》阿德勒心理学，用 RIA++ 六段法构造「人际关系诊断」skill。将一切人际关系烦恼归入三大课题（工作/交友/爱），通过定位课题类型，找到逃避的真相和行动的方向。

---

## R (Reading) — 原文引用

> 「阿德勒把这些过程中产生的人际关系分为『工作课题』『交友课题』和『爱的课题』这三类，又统称为『人生课题』。……人际关系有距离和深度，为了强调这一点，阿德勒也曾使用『三大羁绊』这样的表达方式。」

> 「工作上的人际关系门槛最低。因为有着成果这一简单易懂的共同目标，即使有些不投缘也可以合作，而且因工作这一点结成的关系，在下班或者转行后就又可以变回他人关系。」

> 「交友课题是指脱离了工作的更广泛意义上的朋友关系。正因为没有了工作关系那样的强制力，所以也就更加难以开始和发展。」

> 「爱的课题可以分为两个阶段：一个就是所谓的恋爱关系，而另一个就是与家人的关系，特别是亲子关系。在工作、交友和爱这三大课题中，爱之课题恐怕是最难的课题。」

> 「阿德勒把这种企图设立种种借口来回避人生课题的情况叫做『人生谎言』。对于自己目前所处的状态，把责任转嫁给别人，通过归咎于他人或者环境来回避人生课题。」

> —— 第三夜·第20-25节

> 「行为方面的目标：① 自立 ② 与社会和谐共处。
> 支撑这种行为的心理方面的目标：① 我有能力的意识 ② 人人都是我的伙伴的意识。」
>
> —— 第三夜·第20节

## I (Interpretation) — 核心骨架

**一切人际烦恼皆可归入三大课题，每个课题有不同的痛苦模式和逃避策略。**

### 三大课题速览

| 课题 | 核心关系 | 距离/难度 | 逃避的典型借口 |
|------|---------|-----------|---------------|
| 🏢 **工作课题** | 同事、上下级、客户 | 距离远·门槛低 | "工作没意义""公司太烂""我不适合这行" |
| 🫂 **交友课题** | 朋友、社交圈、知己 | 距离中·难度中 | "交朋友太麻烦""没人理解我""社恐" |
| ❤️ **爱的课题** | 伴侣、亲子、家人 | 距离近·难度最高 | "遇不到对的人""家人不理解我""婚姻是坟墓" |

### 诊断逻辑

1. **定位课题** → 最大的痛苦发生在哪个关系领域？
2. **识别逃避策略** → 你在用哪类借口回避这个课题？
3. **追问深层目的** → 回避这个课题，你得到了什么"好处"？
4. **切换视角** → 从"这个人/这些人对我做了什么"转向"我能为这段关系做什么"

### 行为目标与心理目标的对照

- 行为目标①【自立】→ 对应心理目标①【我有能力的意识】→ 通过自我接纳实现
- 行为目标②【与社会和谐共处】→ 对应心理目标②【人人都是我的伙伴】→ 通过他者信赖和他者贡献实现

**诊断不是贴标签，而是定位手术刀。** 知道问题在哪一个课题领域，才能精准选择相邻skill来介入。

## A1 (Past Application) — 书中案例

### 案例① 工作课题逃避：因面试失败而怀疑工作意义的求职者（c12）

**场景**：求职者投出简历、参加面试，却未被任何公司录取。自尊心受到极大伤害，思来想去开始怀疑"工作的意义"。

**诊断**：这不是"工作意义"的问题，而是**工作课题**的逃避。此人并非讨厌工作本身，而是讨厌"因为工作而受到他人的批评和指责，讨厌被贴上'你没有能力'或者'你不适合这个工作'之类的无能标签，更讨厌无可替代的'我'的尊严受到伤害"。

**逃避策略**：将"面试失败"转化为"工作没意义"的哲学思考——用抽象质疑替代具体行动。

**转化路径**：识别这是工作课题 → 课题分离（面试结果由企业决定，但继续尝试是自己的课题）→ 区分"被拒绝"和"我不够好"（被拒绝≠自我价值被否定）

### 案例② 交友课题逃避：将他人视为敌人的青年（c10）

**场景**：青年无法把他人看成伙伴，总在心里把别人想成敌人。哲人追问："你为什么把别人看成是敌人而不能认为是伙伴呢？那是因为勇气受挫的你在逃避人生的课题。"

**诊断**：这是**交友课题**的逃避。青年害怕在人际关系中受伤，所以先发制人地把所有人都预设为"可能伤害我的人"。

**逃避策略**：使用"对方有问题"的借口——如果对方是敌人，那么"不交往"就成了合理的选择。用"他人不好"来正当化自己的社交退缩。

**转化路径**：识别这是交友课题 → 课题分离（别人怎么对我是别人的课题，我怎么回应是我的课题）→ 他者信赖（从"先怀疑"转向"先相信"）

### 案例③ 爱的课题逃避：丈夫把工作当作逃避家庭的借口（c14）

**场景**：一位父亲是典型的工作狂，一心只想在工作上出成绩，以"挣钱养家"为由支配家人，对家务、育儿、夫妻交流不闻不问。

**诊断**：这是**爱的课题**的逃避。他以"工作忙"为借口回避家庭关系中的责任和深度交流。阿德勒指出，这本质上和闭门不出的孩子是同一类问题——将某个课题（工作）放大，用来逃避其他课题（爱）。

**逃避策略**：使用"我在为家庭付出/牺牲"的道德正确性来正当化对其他课题的逃避。以行为标准（我挣钱了）来替代关系标准（我在关系中投入了）。

**转化路径**：识别爱的课题被掩盖 → 打破"工作=一切"的人生谎言 → 重新定义工作（家庭中的劳动/育儿/陪伴也是"工作"）→ 从"我付出"转向"我连接"

### 案例④ 人生谎言的典型：讨厌A的人（c15）

**场景**：青年讨厌某个人A，理由是"A身上有让人无法容忍的缺点"。哲人指出：不是A的缺点导致你讨厌他，而是你先有"要讨厌A"的目的，才找出符合这个目的的缺点。

**诊断**：这是**兼跨交友课题和爱的课题**的人生谎言。目的是逃避与A的人际关系——把责任转嫁给A的"缺点"，让自己不用面对"我其实不敢/不想和A深入交往"这个真相。

**转化路径**：识别人生谎言 → 问自己"我对A的讨厌，在帮我逃避什么关系课题？" → 即使决定疏远，也要承认这是自己的选择而非对方的过错

## A2 (Future Trigger) ★ — 触发场景

### 用户情境

| 课题类型 | 典型情境 | 语言信号 |
|---------|---------|---------|
| 🏢 **工作课题** | 不想上班/对工作没有热情/频繁换工作/职场人际冲突/害怕汇报被批评 | "工作没意思""公司太差""老板有病""我不适合这行""我只是为了钱" |
| 🫂 **交友课题** | 没有朋友/觉得交朋友太累/总怀疑别人不真心/社交后极度疲惫/觉得"没人懂我" | "社交太累了""没一个真朋友""我不需要别人""大家都虚伪""融入不了" |
| ❤️ **爱的课题** | 害怕进入恋爱/亲密关系恐惧/亲子冲突/与伴侣冷战/觉得家人不理解自己 | "遇不到对的人""婚姻是坟墓""父母根本不听我说""他/她变了""我不想结婚" |
| 🌀 **混合课题** | 上述两种或三种同时出现；用某个课题的成功掩盖其他课题的失败（如"工作狂"） | "虽然家庭不睦但我事业成功""我朋友多但就是找不到对象" |

### 判断标准

当用户出现以下**任意一种**模式时，启动人际关系诊断：

1. **课题混淆**：把A课题的问题归因到B课题（如说"我工作不顺是因为没遇到好伴侣"）
2. **课题偏废**：过度投入一个课题来逃避其他课题（如全身心工作→逃避家庭和社交）
3. **课题逃避**：使用"人生谎言"将人际关系困境归咎于外部（"都怪XX太差劲/环境太烂"）
4. **课题恐惧**：完全回避某类关系（一个朋友没有/从不恋爱/与家人断绝联系）

### 与相邻skill的边界

| 当用户的困扰聚焦于…… | 先使用 |
|-------------------|--------|
| 分不清这是谁的责任/谁的课题 → | 课题分离 |
| 害怕被讨厌/在意他人评价 → | 被讨厌的勇气 |
| 用"因为A所以做不到B"的借口 → | 自卑感转化 / 目的论思维 |
| 不知道该在哪个领域使劲 → | **人际关系诊断（本skill）** |

## E (Execution) — 1-2-3 可执行步骤

### 步骤1：定位——"我的主要痛苦在哪个课题？"

拿出一张纸（或在脑中自问），逐一扫描三个领域：

**问自己：**
> 🏢 **工作课题**（0-10分）—— 我在职场关系/学习/工作中的痛苦程度有多高？我是否在用"工作没意义"来逃避面对工作中的具体关系？
>
> 🫂 **交友课题**（0-10分）—— 我有多少可以坦诚交流的朋友？我是否因为害怕受伤而干脆不交朋友？
>
> ❤️ **爱的课题**（0-10分）—— 我在亲密关系/亲子关系中有多痛苦？我是否用其他课题的成功来掩盖这里的失败？

**诊断结果**：得分最高的1-2个课题，就是你当下最主要的"人生课题战场"。

**判停条件**：如果三个课题得分都≥7分——说明你正处于全面的人际危机中。此时不要同时处理所有课题，先选**你认为最轻的一个**入手。

### 步骤2：拆解——"我在逃避什么？"

针对步骤1中得分最高的课题，追问三个问题：

> ① 在这段关系中，**我最害怕发生什么**？（被拒绝？被批评？被看穿？被抛弃？）
> ② 我现在的行为（退缩/攻击/讨好/漠视）在帮我**逃避什么**？
> ③ 如果我用"人生谎言"来解释——我把责任归咎于谁/什么？

**转化句式**：
- 从："我讨厌上班因为同事太烂"
- 到："我不想面对同事，是因为我害怕被他们评价。我把'同事烂'当作不去的借口。"
- 再问："如果明天同事都变成我最好的朋友——我会喜欢上班吗？"（如果答案是"仍然不会"——说明问题不在工作在爱课题或交友课题）

**判停条件**：如果你能清晰说出"我真正怕的是____"，进入步骤3。如果你仍然觉得"就是对方/环境的问题"——回到相邻skill「课题分离」。

### 步骤3：行动——"我不逃了，第一步做什么？"

根据定位的课题，选择对应的最小行动：

**🏢 工作课题的最小行动：**
- 明天主动对某个同事说一句真诚的"辛苦了"或"谢谢"
- 如果怕被批评——下次汇报前先问"您最关注的是哪个方面？"
- 如果觉得工作没意义——写下这份工作对他人（客户/团队/社会）的3个真实贡献

**🫂 交友课题的最小行动：**
- 主动联系一个很久没联系的老朋友，发一条微信："突然想到你，最近怎么样？"
- 参加一次有陌生人的小型线下活动——不要求"交到朋友"，只要求"和一个陌生人说三句话"
- 对现有关系主动付出一次（推荐一本书/分享一个有用信息/主动约一次饭）

**❤️ 爱的课题的最小行动：**
- 对伴侣/父母做一件"不期待回报"的小事（倒一杯水、认真听ta说5分钟、主动说"我爱你/辛苦了"）
- 如果处于冲突中——先停止"搜集对方的缺点"（参考c15），问自己："我是想赢，还是想修复？"
- 每周安排一次"无手机对谈时间"——15分钟，只聆听，不评判，不打断，不给建议

**完成标准**：你至少完成了1个最小行动，且完成后能说出：
- "这个行动让我感到______（恐惧/轻松/尴尬/有意义）"
- "继续做这件事的阻力主要来自______（外界/我的习惯/我的恐惧）"
- 你已经开始从"我被关系困扰"转向"我在关系中行动"。

## B (Boundary) ★ — 边界与盲点

### 不适用场景

1. **本质上是能力/技能问题**：如果用户的问题不是人际关系层面的，而是技能不足（如技术不过关导致工作不顺）——先解决能力问题，再谈关系课题。不要把一切问题都"诊断"成人际关系问题。
2. **结构性/系统性压迫**：职场PUA、家庭暴力、种族/性别歧视等系统性不公——这不是"个人的人际关系课题"，而是需要外部支持系统介入的侵权问题。不要用"你在逃避课题"来二次伤害受害者。
3. **临床心理障碍急性期**：重度抑郁、社交焦虑障碍（SAD）、人格障碍等——症状不是"逃避"而是①疾病表现。此时应推荐专业心理治疗，而非阿德勒式的"诊断三大课题"。

### 理论盲点

1. **三大课题的边界并不清晰**：现实中大量关系同时跨越多个课题（如夫妻共同创业→既是爱的课题又是工作课题；同事成为挚友→从工作课题过渡到交友课题）。强行归入单一课题可能简化了问题的复杂性。
2. **"一切烦恼皆源于人际关系"的绝对化**：阿德勒这一断言排除了生理性痛苦（疾病、疼痛、饥饿）、存在性焦虑（死亡、意义、孤独）等独立于人关系的痛苦来源。三大课题诊断不适用于这些领域。
3. **低估文化差异**：在东亚集体主义文化中，"工作课题""交友课题""爱的课题"三者紧密交织，不像书中描述的那样可以清晰分离。例如：职场中的上下级关系（工作课题）往往带有家族式的情感义务（爱的课题的影子）。诊断时要考虑文化情境。

### 使用警告

1. **诊断≠审判**：定位课题的目的是找到行动入口，不是给人贴"你就是逃避所有课题"的标签。
2. **一个课题一个课题来**：不要同时处理所有三个课题。阿德勒说"领悟需要自身岁数一半的时间"——慢慢来。
3. **配合共同体感觉使用**：诊断出课题后，最终要走向"我如何为这个课题中的他人做贡献"，而非"我如何在这段关系中保护自己/赢过对方"。
4. **人生谎言是勇气问题，不是道德问题**：如书中强调的，"我们不应该用善恶来区分人生课题或人生谎言，应该谈的是勇气问题"——避免让用户感到被谴责。

### 推荐组合路径

| 诊断结果 | 推荐路径 |
|---------|---------|
| 工作课题困扰 | 课题分离 → 目的论思维 → 自卑感转化 → 横向关系 |
| 交友课题困扰 | 课题分离 → 他者信赖 → 被讨厌的勇气 → 主动付出 |
| 爱的课题困扰 | 课题分离 → 自我接纳 → 他者信赖 → 他者贡献 |
| 混合/不明 | 先做"此时此刻"（活在当下）→ 再回头看课题定位 |
